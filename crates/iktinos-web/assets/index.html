The server is running. The page that shows the sessions is not built into this version yet.

What it will be drawn from is already served, as JSON:

  • /api/sessions: every session, the latest first
  • /api/sessions/<id>: one session, with its usage, its recent tool calls and its subagents
  • /api/sessions/<id>/trace: its latest interactions, each as a tree
  • /api/sessions/<id>/calls/<call id>/output: the whole output of one tool call
  • /api/sessions/<id>/responses/<message id>: the whole text of one response
  • /api/events: server-sent events, one each time something changed
